
# MySQL 启动选项与系统变量

## 启动选项
- 服务端启动参数
  - --skip_networking：禁止客户端使用 TCP/IP
  - --default-storage-engine：设置默认存储引擎
  - --defaults-extra-file：额外配置文件路径
  - --defaults-file：只加载指定配置文件，不查找默认路径
- 示例：
  - mysqld --default-storage-engine=MyISAM

## 配置文件
- 命令行启动选项优先级 > 配置文件
- Windows 配置文件路径
  - %WINDIR%\my.ini，%WINDIR%\my.cnf
  - C:\my.ini，C:\my.cnf
  - BASEDIR\my.ini，BASEDIR\my.cnf
  - defaults-extra-file：命令行指定
  - %APPDATA%\MySQL\.mylogin.cnf：仅客户端登录选项
- 类 Unix 配置文件路径
  - /etc/my.cnf、/etc/mysql/my.cnf、SYSCONFDIR/my.cnf：服务端和客户端选项
  - $MYSQL_HOME/my.cnf：仅服务器选项
  - defaults-extra-file：命令行指定
  - ~/.my.cnf：用户特定选项
  - ~/.mylogin.cnf：仅客户端登录选项
- 配置文件组
  - [server]、[mysqld]、[mysqld_safe]、[client]、[mysql]、[mysqladmin]
- 组与命令对应关系
  - mysqld：读取 [mysqld],[server],[mysqld-版本号]
  - mysqld_safe：读取 [mysqld],[server],[mysqld_safe]
  - mysql：读取 [client],[mysql]
  - mysqldump：读取 [client],[mysqldump]
  - mysqladmin：读取 [client],[mysqladmin]
  - mysqlcheck：读取 [client],[mysqlcheck]
  - mysqlbinlog：读取 [client],[mysqlbinlog]
  - mysqlshow：读取 [client],[mysqlshow]
  - mysqlimport：读取 [client],[mysqlimport]
  - mysqlslap：读取 [client],[mysqlslap]

## 系统变量
- MySQL 服务器运行过程影响程序行为的变量
- 查看系统变量
  - SHOW VARIABLES [LIKE 'pattern'];
- 设置系统变量
  - SET [GLOBAL|SESSION] 变量名 = 值;
  - SET @@GLOBAL.变量名 = 值;
  - SET @@SESSION.变量名 = 值;
  - SET 变量名 = 值;（默认 SESSION）
- 系统变量作用范围
  - GLOBAL：全局变量，影响服务器整体
  - SESSION：会话变量，影响当前客户端连接
- 系统变量动态修改，无需重启服务器

### 常用系统变量

#### 连接与安全
- port：3306，服务端端口
- bind_address：0.0.0.0，绑定 IP
- max_connections：151，最大客户端连接数
- wait_timeout：28800，非交互超时（秒）
- interactive_timeout：28800，交互超时（秒）
- skip_name_resolve：OFF，是否禁用 DNS 解析
- sql_mode：STRICT_TRANS_TABLES,NO_ENGINE_SUBSTITUTION，SQL 模式

#### 存储引擎与表相关
- default_storage_engine：InnoDB，默认存储引擎
- innodb_file_per_table：ON，每表单独数据文件
- innodb_buffer_pool_size：128MB，InnoDB 缓冲池
- innodb_log_file_size：48MB，redo log 文件
- character_set_server：utf8mb4，默认字符集
- collation_server：utf8mb4_0900_ai_ci，默认排序规则

#### 查询与性能相关
- query_cache_size：0，查询缓存大小（8.0 已弃用）
- tmp_table_size：16MB，内存临时表大小
- max_heap_table_size：16MB，内存表最大尺寸
- slow_query_log：OFF，是否开启慢查询日志
- long_query_time：10，慢查询阈值（秒）
- log_bin：OFF，是否开启二进制日志

#### 日志相关
- general_log：OFF，是否开启通用查询日志
- general_log_file：HOSTname.log，通用日志路径
- slow_query_log_file：HOSTname-slow.log，慢查询日志路径
- log_error：hostname.err，错误日志路径

#### 内存与缓存相关
- key_buffer_size：8MB，MyISAM 索引缓存
- innodb_buffer_pool_size：128MB，InnoDB 缓冲池
- innodb_log_buffer_size：16MB，InnoDB redo log 缓冲
- sort_buffer_size：256KB，排序操作缓冲
- read_buffer_size：128KB，顺序扫描缓冲
- read_rnd_buffer_size：256KB，随机读取缓冲

#### 时间与时区相关
- time_zone：SYSTEM，MySQL 当前时区
- system_time_zone：系统默认时区
- default_time_zone：SYSTEM，默认时间戳
