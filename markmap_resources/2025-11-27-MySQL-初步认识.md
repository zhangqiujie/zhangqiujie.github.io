# MySQL 服务端/客户端架构

## 架构概述
MySQL采用服务端+客户端架构，使用流程：

1. 启动服务器程序（mysqld 或 mysqld_safe）
2. 启动客户端程序 mysql 并连接服务器
3. 客户端发送 SQL 请求，服务器处理并返回结果

## MySQL 安装

### Unix 系统安装
brew install mysql

### 安装目录
- 主文件夹：`/usr/local/mysql`
- 可执行文件：`/usr/local/mysql/bin`
- 推荐加入 PATH：
export PATH=/usr/local/mysql/bin:$PATH
- 启动服务器示例：
mysqld

## 启动 MySQL 服务器程序

### mysqld
- 直接启动服务器进程

### mysqld_safe
- 启动 mysqld 并附带监控进程
- 可将错误日志和诊断信息重定向到文件
- 常用于传统 VM / 物理机生产环境

### 生产环境启动建议
- 容器化部署：直接运行 `mysqld`，由容器 restart 策略管理
- VM/物理机：使用 `systemd + mysqld`

## 启动 MySQL 客户端程序
mysql -h主机名 -u用户名 -p密码

| 参数 | 含义 |
|------|------|
| -h   | 服务器地址，默认 localhost/127.0.0.1 |
| -u   | 用户名 |
| -p   | 密码（-p和密码之间无空格） |
| -P   | 端口号 |

## 客户端与服务器连接方式
1. **TCP/IP**  
   - 默认端口 3306  
   - 跨网络通信
2. **命名管道 / 共享内存**（Windows）
3. **Unix 域套接字文件**（类 Unix 系统本地通信）

## 服务器处理客户端请求流程
1. **连接管理**  
   - 每个客户端创建一个线程处理交互
   - 线程可复用，减少创建/销毁开销
2. **解析与优化**
   - 查询缓存（MySQL 8.0 已废弃）
   - 语法解析：分析 SQL 文本，提取表和查询条件
   - 查询优化：生成执行计划（可使用 `EXPLAIN` 查看）
3. **存储引擎处理**
   - `MySQL server`：负责连接管理、解析、优化等
   - `存储引擎`：负责实际数据存取，按执行计划提供数据

## 常用存储引擎

| 存储引擎 | 描述 |
|----------|------|
| InnoDB   | 支持事务和外键，MySQL 默认引擎 |
| MyISAM   | 非事务存储引擎 |

## 创建表时指定存储引擎
CREATE TABLE 表名 (
    列定义...
) ENGINE = 存储引擎名称;
