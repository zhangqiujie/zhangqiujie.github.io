## Docker 镜像常用命令

1. 拉取镜像：

```
docker pull [选项] [Docker Registry 地址[:端口号]/]仓库名[:标签]
docker pull ubuntu
docker pull ubuntu:18.04
```

其中默认标签是latest。

2. 以镜像为基础运行容器：

```
docker run -it ubuntu bash
```
- `-i`：交互式操作
- `-t`: 终端
- `bash`：放在镜像名后的是 命令，这里我们希望有个交互式 Shell，因此用的是 bash。

3. 列出本地镜像：
```
docker image ls #包含顶层镜像
docker image ls -a #包含顶层镜像和中间层镜像
docker image ls -q #列出id里表

docker image ls --format "{{.ID}}: {{.Repository}}" #以指定格式输出，这里是key:value的形式
docker image ls --format "table {{.ID}}\t{{.Repository}}\t{{.Tag}}" #以表格形式输出
```

4. 查看镜像、容器、数据卷所占用的空间：
```
docker system df
```

5. 删除虚悬镜像 ---  即`<none>:<none>`、无标签、无容器引用的中间层镜像。
```
docker image prune
```

6. 删除本地镜像, 可以指定`长ID`，`短ID`，`仓库:标签`或`镜像摘要`。
```
docker image rm <镜像1> [<镜像2> ...]
```

镜像的唯一标识是其 ID 和摘要。而标签和镜像的关系是多对一的。

当使用 IMAGE ID 或 digest 删除镜像时。行为如下：

- Docker 找出所有指向该镜像 ID 的标签（例如 myapp:v1, myapp:latest 等）。
- 一次性全部取消这些标签（Untagged）。
- 检查是否有容器或其它镜像依赖该镜像。
- 只有在没有任何依赖的情况下，才会执行实际的删除操作（Deleted），释放磁盘空间。

当指定`仓库:标签`时，行为如下：

- 仅取消指定的这个标签。
- 检查该镜像是否还有其他标签以及是否有容器或其它镜像依赖它。
- 只有在所有标签都被移除且无任何容器或层依赖时，才会执行实际的删除操作（Deleted）。

7. 检查 Docker 容器文件系统相对于其创建时所基于的镜像发生了哪些更改。结果里的A是新增，D是删除，C是修改。
```
docker diff <容器名/ID>
```

8. 进入容器：
```
docker exec -it <容器> bash
```

9. 使用`docker commit`，把容器保存为镜像（便于理解，生产不常用）
```
docker commit [选项] <容器ID或容器名> [<仓库名>[:<标签>]]
```

`docker commit`可能不只是保存了你预期内的文件改动，还有一些缓存，编译之类的额外文件，有不可控性。生成的镜像也被称为 黑箱镜像。
